# Шпаргалка к защите

На защите каждому участнику зададут 5 вопросов по **любой** части проекта, и финальная оценка умножается на долю правильных ответов. Ниже — всё, что используется в `german_credit_project.ipynb`.

## Библиотеки

| Импорт | Библиотека | Зачем |
|---|---|---|
| `pd` | pandas | таблицы (DataFrame), чтение данных, группировки |
| `np` | numpy | математика с массивами, `np.exp` |
| `plt` | matplotlib.pyplot | основа для графиков, `plt.subplots`, `plt.show` |
| `sns` | seaborn | статистические графики поверх matplotlib |
| `stats` | scipy.stats | статистические тесты и корреляции |
| `ztest`, `proportions_ztest` | statsmodels | z-тесты для среднего и для доли |
| `StandardScaler`, `LabelEncoder`, `OrdinalEncoder` | sklearn.preprocessing | масштабирование и кодирование |
| `train_test_split` | sklearn.model_selection | деление на train/test |
| `LogisticRegression` | sklearn.linear_model | логистическая регрессия |
| `accuracy_score` и др. | sklearn.metrics | метрики качества |

## Функции и параметры

**pandas**
- `pd.read_excel(path)` — читает Excel в DataFrame.
- `df.drop(columns='Unnamed: 0')` — удаляет столбец (служебный индекс строки).
- `df.shape` — (строки, столбцы); `df.dtypes` — формат каждого столбца; `df.head()` — первые 5 строк.
- `df.isna().sum()` — количество пропусков в каждом столбце.
- `df[col].mode()[0]` — мода; `[0]`, потому что `mode()` возвращает Series (мод может быть несколько).
- `fillna(value)` — заполняет пропуски значением.
- `df.duplicated().sum()` — число полных дубликатов; `drop_duplicates()` — удаляет их.
- `df.copy()` — независимая копия (изменения не затронут исходный DataFrame).
- `describe()` — count, mean, std, min, квартили, max; для текстовых столбцов — count, unique, top (мода), freq.
- `quantile(0.25)` — 25%-й квантиль (Q1).
- `value_counts(normalize=True)` — доли вместо частот.
- `groupby('target')[cols].median()` — медианы по группам.
- `pd.crosstab(a, b)` — таблица сопряжённости (частоты пар категорий).
- `pd.get_dummies(df, columns=['Sex'], drop_first=True, dtype=int)` — One-Hot кодирование; `drop_first=True` удаляет первый столбец, чтобы не было лишнего (мультиколлинеарного) столбца.
- `map({1: 0, 2: 1})` — заменяет значения по словарю.
- `df.corr(method='spearman')` — корреляционная матрица Спирмена.
- `sort_values(ascending=False)` — сортировка **по убыванию**; `head(5)` — первые 5.

**Графики**
- `sns.boxplot` — ящик с усами: линия — медиана, ящик — от Q1 до Q3, усы — до 1.5·IQR, точки — выбросы.
- `sns.histplot(kde=True)` — гистограмма + сглаженная оценка плотности.
- `plot(kind='bar')` — столбчатая диаграмма.
- `sns.violinplot(x, y, hue, split=True)` — скрипичный график: форма распределения + ящик внутри; `split=True` рисует две группы `hue` на половинках одной «скрипки».
- `sns.heatmap(annot=True, fmt='.2f', cmap='coolwarm', center=0)` — тепловая карта; `annot` — подписи чисел, `fmt` — 2 знака после запятой.
- `plt.subplots(1, 3, figsize=(15, 4))` — сетка 1×3 графиков размером 15×4 дюйма; `plt.tight_layout()` — убирает наложения.

**sklearn**
- `LabelEncoder().fit_transform` — категории → 0, 1, 2… по алфавиту (для номинальных).
- `OrdinalEncoder(categories=[[...]])` — категории → числа в **заданном** порядке (для порядковых).
- `StandardScaler` — z = (x − среднее) / σ, после него среднее 0 и σ = 1.
- `fit` — обучить (запомнить параметры), `transform` — применить, `fit_transform` — оба шага.
- `train_test_split(test_size=0.25, random_state=42, stratify=y)` — 25% в тест; `random_state` — воспроизводимость; `stratify` — одинаковая доля классов в train и test.
- `LogisticRegression(class_weight='balanced', max_iter=1000)` — `class_weight` увеличивает вес редкого класса; `max_iter` — максимум итераций оптимизации.
- `model.coef_`, `model.intercept_` — коэффициенты и свободный член.
- `predict` — класс (0/1); `predict_proba(X)[:, 1]` — вероятность класса 1.

**scipy / statsmodels**
- `stats.shapiro` — Шапиро–Уилк, H₀: распределение нормальное.
- `ztest(x, value=3000)` — z-тест для среднего (дисперсия считается известной).
- `stats.ttest_1samp(x, popmean=35)` — одновыборочный t-тест.
- `stats.levene` — равенство дисперсий двух групп.
- `stats.ttest_ind(a, b, equal_var=False)` — t-тест Уэлча для независимых выборок с разными дисперсиями.
- `stats.ttest_rel` — парный t-тест (в проекте не применим: нет парных измерений).
- `proportions_ztest(count, nobs, value=0.3)` — z-тест для доли.
- `stats.chi2_contingency(table)` — хи-квадрат на независимость; предпосылка: ожидаемые частоты ≥ 5.
- `stats.mannwhitneyu(a, b, alternative='greater')` — непараметрический тест для двух групп; `greater` — односторонняя H₁ «первая выборка больше».
- `stats.pointbiserialr` — корреляция бинарного и количественного признаков.

## Понятия

- **Типы признаков:** количественный дискретный (счётные значения: возраст в годах, срок в месяцах), количественный непрерывный (сумма), бинарный (2 значения), номинальный (без порядка: цель кредита), порядковый (есть порядок: little < moderate < rich).
- **МЦТ** — меры центральной тенденции: среднее, медиана, мода. Для категориальных — только мода.
- **Правило 3σ:** выброс — значение дальше 3 стандартных отклонений от среднего.
- **IQR** = Q3 − Q1; выброс — вне [Q1 − 1.5·IQR; Q3 + 1.5·IQR].
- **Асимметрия (skew) > 0** — длинный правый хвост, среднее больше медианы.
- **Пирсон** — линейная связь; **Спирмен** — монотонная, по рангам, устойчив к выбросам.
- **p-value** — вероятность получить такой или более экстремальный результат, если H₀ верна. Если p < 0.05, H₀ отвергаем.
- **Логистическая регрессия:** ln(p / (1 − p)) = b₀ + b₁x₁ + …; exp(b) — отношение шансов: во сколько раз меняются шансы при росте признака на 1.
- **Accuracy** — доля верных ответов; **Precision** — из предсказанных «плохих» сколько действительно плохие; **Recall** — из действительно плохих сколько найдено; **F1** — гармоническое среднее precision и recall; **ROC-AUC** — качество ранжирования (0.5 — случайно, 1 — идеально).
