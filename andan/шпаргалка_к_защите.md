## Функции и параметры по разделам

**Описание данных**
- `df.head()` — первые 5 строк; `df.shape` — (строки, столбцы); `df.dtypes` — формат каждого столбца.
- `df.drop(columns='Unnamed: 0')` — удаляет столбец. Исходный df не меняется, поэтому результат сохраняем: `df = ...`.
- Форматы: `int64` — целые числа, `float64` — дробные, `object`/`str` — текст.

**Пропуски и дубликаты**
- `df.isna().sum()` — количество пропусков в каждом столбце.
- `df[col].mode()[0]` — мода. `[0]` нужен, потому что `mode()` возвращает столбец (мод может быть несколько).
- `fillna(значение)` — заполняет пропуски.
- `df.duplicated().sum()` — число полных дубликатов; `drop_duplicates()` — удаляет их.
- `df.copy()` — независимая копия, чтобы изменения не затронули исходную таблицу.

**Выбросы**
- `sns.boxplot(data=df, x=col)` — ящик с усами: линия внутри — медиана, ящик — от Q1 до Q3, усы — до 1.5·IQR, точки — выбросы.
- `quantile(0.25)` — первый квартиль Q1, `quantile(0.75)` — Q3.
- `.between(left, right)` — True, если значение в интервале (границы включены); используется как фильтр.
- `.copy()` после фильтра — делаем новую таблицу, а не ссылку на кусок старой.

**Визуализация**
- `df[col].plot(kind='hist', bins=20)` — гистограмма; `bins` — число столбиков.
- `df[col].value_counts().plot(kind='bar')` — столбчатая диаграмма частот.
- `sns.violinplot(data=df, x='target', y=col)` — скрипичный график: форма распределения + ящик с усами внутри.
- `title=col`, `figsize=(5, 3)` — заголовок и размер графика.

**Описательные статистики**
- `describe()` — count, mean, std, min, 25%, 50% (медиана), 75%, max. Для текстовых столбцов — count, unique (число категорий), top (мода), freq (частота моды).
- `astype(str)` — превращает столбцы в текст, чтобы `describe()` показал моду и частоты (`Job` хранится числами).
- `value_counts()` — частоты значений; делим на `df.shape[0]` → доли.
- `groupby('target')[cols].median()` — медианы по группам.

**Перекодирование**
- `apply(lambda x: 1 if x == 2 else 0)` — применяет функцию к каждой ячейке: 2 → 1, всё остальное → 0.
- `pd.get_dummies(df, columns=['Sex'], drop_first=True, dtype=int)` — One-Hot. `drop_first=True` удаляет первый столбец (`Sex_female`), потому что он лишний: если `Sex_male` = 0, то это женщина. `dtype=int` — 0/1 вместо True/False.
- `LabelEncoder().fit_transform(df[col])` — категории → 0, 1, 2… по алфавиту (для номинальных признаков).
- `OrdinalEncoder().fit_transform(df[[cols]])` — то же для нескольких столбцов (двойные скобки = таблица).

**Корреляция**
- `df[[a, b]].corr()` — корреляция Пирсона (по умолчанию).
- `df.corr(method='spearman')` — корреляция Спирмена: монотонная связь, по рангам, устойчива к выбросам.
- `corr['target'].drop('target')` — столбец корреляций с target без корреляции target с самим собой.
- `sort_values(key=abs, ascending=False)` — сортировка по модулю (по силе связи), **по убыванию**; `head(5)` — первые 5.

**Масштабирование**
- `StandardScaler` — z = (x − среднее) / σ; после него среднее 0, стандартное отклонение 1.
- `fit` — посчитать среднее и σ, `transform` — применить формулу, `fit_transform` — оба шага сразу.

**Регрессия**
- `train_test_split(X, y, random_state=42, test_size=0.3)` — 30% наблюдений в тест; `random_state` — одинаковое разбиение при каждом запуске.
- `model.fit(X_train, y_train)` — обучение модели.
- `model.coef_.flatten()` — коэффициенты (flatten превращает матрицу в вектор); `model.feature_names_in_` — названия признаков; `model.intercept_` — свободный член.
- `np.exp(коэффициент)` — отношение шансов.
- `model.predict(X_test)` — классы 0/1 (порог вероятности 0.5); `model.predict_proba(X_test)[:, 1]` — вероятность класса 1.
- Метрики accuracy, precision, recall, f1 считаются по **классам**, ROC-AUC — по **вероятностям**.
- `confusion_matrix(y_test, pred_class)` — строки — факт, столбцы — предсказание.

**Тесты** (во всех: если p-value < 0.05 — отвергаем H₀)
- `stats.shapiro(x)` — Шапиро–Уилк, H₀: распределение нормальное.
- `ztest(x, value=3000)` — z-тест для среднего, возвращает пару (статистика, p-value).
- `stats.ttest_1samp(x, 35)` — одновыборочный t-тест: сравнивает среднее с числом.
- `stats.ttest_ind(a, b)` — t-тест для двух независимых выборок.
- `stats.ttest_rel(a, b)` — парный t-тест: в проекте **не применим**, нет парных измерений одних и тех же объектов.
- `proportions_ztest(count, nobs, value=0.3)` — z-тест для доли; `res[1]` — p-value.
- `df.pivot_table(index=..., columns=..., values=..., aggfunc='count')` — таблица сопряжённости; `stats.chi2_contingency(t)` — хи-квадрат на независимость.
- `stats.mannwhitneyu(a, b)` — Манн–Уитни: непараметрический тест (не требует нормальности) для двух групп.
- `res.pvalue` — p-value из результата теста.

## Понятия

- **Типы признаков:** количественный дискретный (счётные значения: возраст в годах, срок в месяцах), количественный непрерывный (сумма), бинарный (2 значения), номинальный (без порядка: цель кредита), порядковый (есть порядок: little < moderate < rich).
- **МЦТ** — меры центральной тенденции: среднее, медиана, мода. Для категориальных признаков — только мода.
- **Правило 3σ:** выброс — значение дальше 3 стандартных отклонений от среднего.
- **IQR** = Q3 − Q1; выброс — значение вне [Q1 − 1.5·IQR; Q3 + 1.5·IQR].
- **Среднее > медианы** — правосторонняя асимметрия (длинный хвост справа).
- **Пирсон** — линейная связь; **Спирмен** — монотонная связь.
- **p-value** — вероятность получить такой или более экстремальный результат, если H₀ верна.
- **Логистическая регрессия:** ln(p / (1 − p)) = b₀ + b₁x₁ + …; e^b — во сколько раз меняются шансы при росте признака на 1.
- **Accuracy** — доля верных ответов; **Precision** — из предсказанных «плохих» сколько действительно плохие; **Recall** — из действительно плохих сколько найдено; **F1** — гармоническое среднее precision и recall; **ROC-AUC** — качество ранжирования (0.5 — случайно, 1 — идеально).
